# Face Ancestry Recognition System — Research Limitations

This project contains experimental image classification coursework. **Ancestry, race, and ethnicity cannot be reliably inferred from a face photograph.** Results should never be treated as a person's identity or used to make consequential decisions.

See [`read me.md`](read%20me.md) for repository structure, scripts, known issues, and limitations. The Flask demo is incomplete and must not be publicly deployed without privacy and security review.
